# Сводка

Личный поисковик новостей для Ubuntu: Claude (по подписке Pro) по расписанию ищет свежее по вашим темам, приложение складывает это в ленту, подстраивает её под вас и даёт читать статьи целиком по-русски.

Сейчас здесь только проект перед разработкой:

- [docs/DESIGN.md](docs/DESIGN.md) — исследование, решения, архитектура, этапы;
- [docs/mockups/](docs/mockups/) — статичные макеты экранов в стиле Aqua Linux (`mockup.py` рисует их заново).
