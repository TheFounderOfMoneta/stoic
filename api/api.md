# Stoic API Documentation

Ниже представлен список доступных эндпоинтов API для взаимодействия с системой. Все защищенные эндпоинты требуют передачи заголовка `X-API-Key`.

## Health Check
- `GET /api/v1/health` — проверка состояния сервера и доступности базы данных. Не требует авторизации.

## Метаданные и Сущности
- `GET /api/v1/meta` — получение метаданных системы или справочников.
- `GET /api/v1/entities` — получение списка сущностей (с поддержкой пагинации, например `?limit=100`).
- `GET /api/v1/entities/{entity_id}` — получение детальной информации по конкретной сущности по её ID.

## Поиск
- `GET /api/v1/search` — выполнение полнотекстового поиска (параметр `?q=текст_запроса`).

## Входящие источники (Incoming Sources)
- `GET /api/v1/incoming-sources` — список входящих источников информации (с поддержкой пагинации).
- `GET /api/v1/incoming-sources/{source_id}` — детали конкретного источника.
- `GET /api/v1/incoming-sources/{source_id}/fragments` — получение фрагментов, привязанных к конкретному источнику.

## Фрагменты источников (Source Fragments)
- `GET /api/v1/source-fragments/{fragment_id}` — получение информации по конкретному фрагменту источника.

## Очередь на проверку (Review Queue)
- `GET /api/v1/review-queue` — получение списка элементов, находящихся в очереди на проверку.

## Задачи (Tasks)
- `GET /api/v1/tasks/deadlines/today/count` — получить количество задач на сегодня. (Поддерживаются параметры `?date=YYYY-MM-DD` и `?timezone=...` для указания конкретной даты).
- `GET /api/v1/tasks/deadlines/today` — получить список задач с дедлайном на сегодня (или на дату `?date=YYYY-MM-DD`). Возвращает текст задачи, время дедлайна и статус выполнения.

## Календарь (Calendar)
- `GET /api/v1/calendar/events` — получить события календаря за указанный период (параметры `?date_from=YYYY-MM-DD&date_to=YYYY-MM-DD&timezone=...`).
- `GET /api/v1/calendar/events/today` — получить слоты времени и события календаря на сегодня (параметр `?timezone=...`).

## ИИ-Ассистент (Codex)
- `GET /api/v1/codex/status` — получить статус ИИ-ассистента, включая доступность и список поддерживаемых моделей (например, `gpt-5.2`).
- `POST /api/v1/codex/chat` — отправить сообщение ИИ-ассистенту. 
  Пример тела запроса (JSON):
  ```json
  {
    "message": "Привет, как дела?",
    "conversation_id": "уникальный-идентификатор-чата",
    "model": "gpt-5.2",
    "reasoning_effort": "medium",
    "sandbox": "read-only",
    "approval_policy": "on-request",
    "attachments": []
  }
  ```
