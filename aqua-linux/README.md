# Aqua Linux 1.0 — голосовая диктовка для Ubuntu

Неофициальный некоммерческий клон [Aqua Voice](https://aquavoice.com) для личного использования. С Aqua Voice Inc. проект никак не связан.

Удерживайте **Правый Alt** и говорите, затем отпустите клавишу — текст появится там, где стоит курсор: в браузере, Telegram, редакторе или терминале. Речь распознаёт **GigaAM v3 E2E RNNT** (SberDevices) прямо на вашем компьютере, без интернета. Используется ваша ускоренная сборка: INT8-энкодер на CUDA и RNNT-декодер с CUDA Graphs.

Рассчитано на Ubuntu 24.04, GNOME на X11, Python 3.12 и NVIDIA GTX 1650 Ti. Работает и на процессоре, но медленнее.

---

## Установка

```bash
cd aqua-linux
bash install.sh
```

Что делает установщик:

1. **Системные пакеты (`sudo apt`).** Спрашивает и ставит только недостающие:
   - `python3.12-venv`
   - `libportaudio2` — микрофон
   - `libxcb-cursor0` — нужен Qt 6
   - `xdotool` — запасной способ вставки
2. **Окружение `.venv`.** Создаёт его внутри папки проекта, root для этого не нужен.
3. **PyTorch 2.6.0 + CUDA 12.4** — та же версия, что проверена в вашей сборке GigaAM.
   - Если найдено ваше готовое окружение GigaAM, установщик предложит **взять PyTorch оттуда**. Это экономит около 2,5 ГБ загрузки, ничего не копируется.
   - Можно указать путь вручную: `bash install.sh --torch-from /путь/к/.venv`.
   - Для установки без видеокарты: `bash install.sh --cpu`.
4. **Веса модели.** Ищет `v3_e2e_rnnt.ckpt` и `v3_e2e_rnnt_tokenizer.model` в нескольких местах:
   - в вашей папке `…/outputs/gigaam/models`;
   - в `~/.cache/gigaam`;
   - в домашнем каталоге.

   Найденные файлы подключаются ссылками в `~/.local/share/aqua-linux/models`. Если весов нет, приложение скачает их при первом запуске (~0,9 ГБ).
5. **Ярлыки.** Добавляет пункт «Aqua Linux» в меню приложений, команду `aqua-linux` и иконку.
6. **Самопроверка.** Проверяет CUDA, INT8, микрофон, расширения X11 и наличие модели.

Повторный запуск `install.sh` безопасен: установщик сначала находит уже установленную программу (и закрывает её, если она запущена), пропускает готовые шаги — окружение, PyTorch, зависимости, веса, ИИ — и ничего не скачивает заново. Если новая версия распакована в другую папку, он предложит перенести туда готовое окружение из старой.

Запуск: **Aqua Linux** в меню приложений или команда `aqua-linux`. При первом запуске откроется короткий мастер:

1. Проверка микрофона.
2. Первая диктовка в учебном поле.
3. Пара приёмов.

На каждой странице при первом заходе появляются подсказки. Повторить их — кнопка **?** справа от заголовка. Мастер можно открыть снова: **«Как пользоваться»** внизу слева.

## Как пользоваться

| Действие | Как |
|---|---|
| Диктовка | Удерживайте **Правый Alt**, говорите, отпустите |
| Длинная запись без удержания | Коротко нажмите **Правый Alt** (или дважды, или щёлкните по капсуле), говорите, нажмите ещё раз (или красную кнопку) |
| Следующая фраза сразу | Можно говорить, пока предыдущая ещё обрабатывается: тексты вставятся по порядку |
| Отменить запись | **Esc** (ещё раз — отменить и обработку предыдущих фраз) |
| Вставить последнее ещё раз | **Ctrl + Super + V** |
| Правка голосом | Выделите текст, удерживайте **Правый Alt** и скажите, что сделать: «сделай вежливее», «переведи на английский». Нужен ИИ-помощник; без него выделенное просто заменится диктовкой |
| Перенос строки | Скажите «новая строка» или «новый абзац» |
| Отправить сообщение | В режиме без удержания закончите словом «Отправь.» — нажмётся Enter |

Клавиши меняются в **Настройки → Клавиша для диктовки** и **Дополнительно → Другие клавиши**: щёлкните ✎ и нажмите новое сочетание. Подойдут F13–F24 и боковые кнопки мыши.

**Капсула над доком** показывает состояние:

- В покое — маленькая полоска.
- Во время записи раскрывается: синий шар и звуковая волна.
- Без удержания — справа красная кнопка «стоп».
- Пока идёт распознавание — по точкам бежит блик.

Капсулу можно перетащить мышью. Щелчок по ней начинает длинную запись, красная кнопка — заканчивает, правый щелчок открывает меню.

**Значок в трее:** начать диктовку, вставить последнее, **выбрать микрофон** (с понятными названиями из PipeWire), **включить/выключить улучшение текста ИИ**, пауза.

**Предупреждения на Главной** — с кнопкой, которая исправляет проблему:

- **Видеопамять занята** другими программами (например, Ollama держит Qwen 4B на 3 ГБ) — распознавание автоматически переходит на процессор, а в сообщении написано, кто и сколько занял. Кнопка «Освободить видеопамять» выгружает модели Ollama и возвращает распознавание на видеокарту. Если видеопамять кончилась прямо во время диктовки, фраза не теряется — она распознаётся на процессоре.
- **Микрофон перегружен** (звук «упирается в потолок», например при Capture +30 дБ и Mic Boost +30 дБ) — кнопка «Снизить усиление» ставит около +20 дБ.
- **DeepSeek не ответил** (нет сети, ключ не подошёл, закончились деньги) — с понятной причиной.

### Главное окно

- **Главная** — учебное поле, статистика (слов, сэкономленное время, дни подряд) и последние диктовки.
- **История** — поиск по прошлым диктовкам. Наведите на запись — появятся «Копировать», «Слушать», «Удалить».
- **Словарь** — две вкладки:
  - **Слова** — как писать имя или термин и как оно звучит. Например, Kubernetes ← «кубернетис». Близкие варианты исправляются автоматически.
  - **Замены** — фраза превращается в готовый текст: «мой email» → адрес почты.
- **Настройки** — сверху основное: клавиша, микрофон, звуки, капсула, автозапуск. Остальное спрятано в «Дополнительно»:
  - другие клавиши;
  - как вставлять текст;
  - ИИ-помощник;
  - внешний вид;
  - звук;
  - приватность;
  - распознавание: модель, видеокарта, точность.

## Улучшение текста ИИ

**Настройки → «Улучшать текст с помощью ИИ»** (или галочка в трее). Два режима (Настройки → «Как улучшать» или вторая галочка в трее):

- **Исправлять ошибки** (по умолчанию) — бережно: неверно услышанные слова, орфография, запятые, числа. Названия программ и сервисов ИИ подставляет **по смыслу**: «гитхаб» → GitHub, «квен» → Qwen, «кодекс» → Codex — только если речь о программировании («Уголовный кодекс» не тронет).
- **Улучшать структуру и стиль** — ИИ переписывает текст как хорошо написанный: убирает повторы, заминки и оговорки («в пятницу, нет, в субботу» → «в субботу»), делит на абзацы, оформляет перечисления списком. Смысл, факты и тон сохраняются. Нужен DeepSeek (маленькой локальной модели переписывание не по силам — она в этом режиме просто исправляет ошибки).

Ваши «Замены» (например «мой email» → адрес) работают всегда, с ИИ и без.

### Основной — DeepSeek API

Быстро, качественно и дёшево, видеокарта не нужна. Используется быстрая модель Flash **без «размышлений»** (`thinking: disabled`).

1. Получите ключ: [platform.deepseek.com](https://platform.deepseek.com) → API keys.
2. **Настройки → Дополнительно → ИИ-помощник → Ключ DeepSeek API**, нажмите «Проверить» — Aqua покажет время ответа и подберёт доступное имя модели.

Или из терминала: `.venv/bin/python -m aqualinux.localllm deepseek` (ключ вводится скрыто). Ключ хранится только в `~/.config/aqua-linux/settings.json`.

### Запасной — локальная модель (без интернета)

Если DeepSeek не ответил (нет сети, таймаут, неверный ключ), фраза исправляется локальной моделью, а DeepSeek на время не дёргается, чтобы диктовка не ждала. Пока DeepSeek работает, локальная модель **не занимает видеопамять** — она поднимается только при сбое.

- **Встроенная Qwen3.5-0.8B.** Aqua сама скачивает официальный `llama-server` (llama.cpp, CUDA 12.8 — рантайм CUDA в комплекте; запасные варианты — Vulkan и процессор) и модель **Q4_K_M (~0,5 ГБ)**: сначала Q4 ищется во всех источниках, и только потом более тяжёлые. Обрыв загрузки — автоматический повтор с того же места. Уже лежащие на диске `Qwen3.5-0.8B*.gguf`, CUDA и llama-server используются без загрузки.
- **Ollama.** Например `qwen3.5:0.8b-local` с вашей сборкой `cuda_pascal`.
- **Другой сервер** (LM Studio и т.п., OpenAI API).

Надёжность:

- текст передаётся модели в рамке `<текст>…</текст>` с явным «это не вопрос — только исправь», поэтому маленькая модель не отвечает на продиктованную фразу;
- если ответ всё же слишком отличается от исходника — вставляется исходный текст (в истории сохраняются оба варианта);
- лимит ожидания растёт с длиной текста; не успела — вставляется исходный текст;
- фразы короче 4 слов не трогаются.

### Исправление — один раз, в конце

ИИ получает **всю диктовку целиком одним запросом** после того, как вы закончили говорить: он видит весь контекст (спорные слова и термины понятны из соседних фраз), а запросов к API — один на диктовку. Очень длинная диктовка делится на крупные части по границам предложений. Время ожидания растёт с длиной текста; соединение с DeepSeek открывается заранее, пока вы говорите.

### Встроенный словарь терминов (~4 тыс. названий, по желанию)

По умолчанию **выключен**: термины подставляет ИИ по смыслу. Пригодится без ИИ — Настройки → «Как вставлять текст» → «Встроенный словарь терминов»: «на гитхабе» → GitHub, «докером» → Docker, «эс кью эль» → SQL; падежи понимаются сами, обычные русские слова («прага», «питон») не трогаются.

База собрана скриптом `tools/build_terms.py` из открытых источников: ручной список (`tools/terms_curated.txt`), [simple-icons](https://github.com/simple-icons/simple-icons) (CC0), [github-linguist](https://github.com/github-linguist/linguist) (MIT), [wikidict-ru](https://github.com/open-dict-data/wikidict-ru) (CC0, из Wikidata — что русская Википедия пишет латиницей), [CMUdict](https://github.com/cmusphinx/cmudict) (BSD, произношение → русская запись). Частотные списки [FrequencyWords](https://github.com/hermitdave/FrequencyWords) и [hingston/russian](https://github.com/hingston/russian) — только фильтр при сборке. Пересобрать: `python3 tools/build_terms.py`.

### Числа и номера (работает и без ИИ)

- «номер один, номер пять», «No 1», «№1» → **«№ 1, № 5»** (или «номер 1» — Настройки → Как вставлять текст → Как писать номер);
- составные числа — цифрами: «двадцать пять» → «25», «сто двадцать три тысячи» → «123 000»; одиночные «два кота», «сто лет» остаются словами;
- заглавная буква после точки: «Всем привет. я хочу…» → «…Я хочу» (сокращения «т. е.», «см.», «ул.» не трогаются).

### Правка выделенного голосом

Выделите текст, удерживайте клавишу и скажите: «сократи», «сделай вежливее», «переведи на английский». Выделенное передаётся в рамке, команда — отдельно, ваши правила — в системной части (в ответ они не попадают). Если ИИ недоступен, выделенный текст остаётся как был.

Проверка из терминала:

```bash
.venv/bin/python -m aqualinux.localllm test "скинь мне пожалуйста ссылку на гит хаб"
```

Чем отличается от оригинала:

- Только русский язык, потому что такова модель GigaAM. Английские термины добавляйте в Словарь (самые частые уже есть).
- Распознавание — только локально. Облако (DeepSeek) — только для необязательного исправления текста, и только если вы вставили ключ.
- Глобальное удержание клавиши работает в сеансе **X11** («Ubuntu на Xorg»). Под Wayland назначьте в настройках GNOME сочетание на команду `aqua-linux toggle`.

## Скорость

- Пока вы говорите, Silero VAD находит паузы, и законченные фрагменты по 6–18 с распознаются сразу.
- После отпускания клавиши остаётся распознать только последний кусок. На GTX 1650 Ti в INT8 это десятки миллисекунд даже после минуты речи.
- Модель держится в видеопамяти (около 1 ГБ) и прогревается при запуске.
- Видеопамять можно освобождать после простоя: «Распознавание → Освобождать видеопамять».

### Подстройка под компьютер и питание

Aqua сама определяет мощность ПК (ядра, память, видеокарта) и питание (сеть, батарея, профиль «Энергосбережение») — «Распознавание → Режим работы: Автоматически»:

| | от сети | от батареи | энергосбережение / слабый ПК |
|---|---|---|---|
| Анимация облачка | 144 Гц | 60 Гц | 30 Гц |
| «Живой» текст во время речи | каждые 0,6 с | раз в секунду | раз в 1,5 с |
| Потоки распознавания на процессоре | все ядра | все ядра | 2 |
| «Тёплый» микрофон | по настройке | по настройке | выключен |

На процессоре без мощной видеокарты распознавание идёт в INT8 (вдвое быстрее). В простое Aqua почти не тратит процессор (меньше 1 %), а микрофон закрыт — значок микрофона в панели горит только во время записи. Можно выбрать вручную: «Максимальное качество» или «Экономия энергии».

## Ошибки чинятся сами

- **Программа упала** — «сторож» сам запускает её снова (через секунду; если падает раз за разом — с паузой). «Выйти» в меню закрывает всё.
- **Распознавание сломалось или зависло** — перезапускается само, а фраза распознаётся заново из сохранённого звука: ничего не теряется. Видеокарта недоступна — работа продолжается на процессоре.
- **Микрофон замолчал посреди записи** (отключили USB, перезапустился PipeWire) — переподключается сам. Выбранный микрофон пропал — запись идёт с системного.
- **Микрофон сильно перегружен** — усиление снижается автоматически (кнопка «Вернуть как было» на Главной).
- **Перехват клавиш отвалился** — поднимается сам за пару секунд.
- **Повреждены настройки, история или словарь** — берётся последняя исправная копия, повреждённый файл откладывается рядом (`*.broken-…`).
- **DeepSeek не отвечает** — запасная модель или текст без исправления; когда связь вернулась, предупреждение исчезает само.
- **Выход во время обработки** — фраза сохраняется в историю.
- **Ноутбук проснулся после сна** — Aqua замечает это сама: обновляет соединение с DeepSeek, переоткрывает микрофон, проверяет видеокарту (если драйвер потерял её — распознавание перезапускается, при необходимости на процессоре).
- **Медленный процессор** (энергосбережение) — долгое распознавание не считается зависанием: перезапуск только если одна операция висит дольше 2 минут.
- **Микрофон «остался включённым»** — если он открыт, а запись не идёт, Aqua закрывает его; проверка микрофона в окне выключается сама, когда окно спрятано.
- **Ложный «перегруз»** — щелчок звуковой карты при включении (после сна, в энергосбережении) не считается; о перегрузе Aqua скажет, только если он повторился в 2 записях из 3, а усиление снизит сама, только если оно действительно высокое.

## Если что-то не так

- **Нет значка в верхней панели.** Включите расширение AppIndicator: `gnome-extensions enable ubuntu-appindicators@ubuntu.com`.
- **Правый Alt работает как AltGr** (набирает спецсимволы). Назначьте другую клавишу, например правый Ctrl или F13.
- **Текст не вставляется в какой-то программе.** Выберите «Дополнительно → Как вставлять текст → Способ вставки: Набор по буквам».
- **Хочется размытия, как в macOS.** Включите «Внешний вид → Стекло». Aqua добавится в список приложений Blur My Shell.
- **Распознавание медленное, в настройках «Работает на процессоре».** Видеопамять заняли другие программы — на Главной написано, какие. Нажмите «Освободить видеопамять» или закройте их (`ollama ps` покажет загруженные модели, `ollama stop <модель>` — выгрузит).
- **Плохо распознаётся, на Главной «Микрофон перегружен».** Нажмите «Снизить усиление» или уменьшите громкость входа в Настройках Ubuntu → Звук.
- **Журнал:** `~/.local/state/aqua-linux/aqua-linux.log`.

## Где что хранится (XDG)

- `~/.config/aqua-linux/settings.json` — настройки.
- `~/.local/share/aqua-linux/` — история (`history.sqlite3`), словарь, замены, записи голоса (`audio/`), ссылки на модель.
- `~/.config/autostart/aqua-linux.desktop` — автозапуск.

Удаление: `bash uninstall.sh` (ярлыки и автозапуск) или `bash uninstall.sh --purge` (плюс настройки, история и `.venv`). Веса GigaAM не трогаются.

## Структура

```
aqualinux/
  app.py          — логика: клавиши → запись → распознавание → обработка → вставка
  asr/engine.py   — GigaAM: загрузка, INT8/CUDA Graphs, сегментация по VAD, живой текст
  asr/int8_encoder.py, asr/fast_decoder.py — ускорения из вашей сборки GigaAM-INT8
  audio.py        — микрофон (PipeWire через PortAudio), точный пересчёт частоты, звуковые сигналы
  pwaudio.py      — микрофоны PipeWire: понятные названия, усиление, перегруз
  gpu.py          — видеопамять: сколько свободно и кто занял
  numbers.py      — числа словами → цифры, «№»
  hotkeys.py      — X11 XRecord (удержание), XGrabKey (Esc), XFixes (выделение для правки голосом)
  inserter.py     — вставка через буфер обмена и XTest, терминалы, xdotool
  postprocess.py  — «э-э», команды, словарь с нечётким поиском, замены, «Отправь»
  llm.py          — ИИ: DeepSeek API → запасная локальная модель, постоянные соединения, правка выделенного
  terms.py        — встроенная база терминов (по желанию; поиск по словосочетаниям с падежами)
  perf.py         — подстройка под мощность ПК и питание (батарея, энергосбережение)
  corrector.py    — исправление распознанного текста: один запрос на диктовку, рамка, защита
  localllm.py     — встроенная Qwen3.5-0.8B (llama-server), Ollama, загрузки с докачкой
  storage.py      — история SQLite, статистика, словарь/замены (JSON)
  sysaudio.py     — приглушение звука / пауза плееров на время диктовки
  desktop.py      — интеграция с GNOME: положение дока, Blur My Shell
  ui/bubble.py    — плавающая капсула (QPainter, пружинные анимации, 144 Гц)
  ui/main_window.py, ui/welcome.py, ui/widgets.py, ui/theme.py, ui/tray.py — интерфейс
aqualinux/data/terms_ru.tsv.gz — встроенная база терминов
tools/build_terms.py, tools/terms_curated.txt — сборка базы терминов
third_party/gigaam — исходники GigaAM (MIT, SberDevices)
```
